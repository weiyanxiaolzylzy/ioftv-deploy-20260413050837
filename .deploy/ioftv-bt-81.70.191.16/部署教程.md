# 部署教程 — 81.70.191.16（宝塔上传包版）

> 目标服务器：`81.70.191.16`
> 上传根目录：`/www/wwwroot/`
> 项目目录：`/www/wwwroot/ioftv/`
> 对外访问：`http://81.70.191.16:8080`

## 包内结构

上传包解压后应得到：

```text
ioftv/
├── dist/
├── ifc/
│   └── dist/
├── server/
├── public/
├── banzu/
├── 单个构件质检表/
├── app.py
├── ifc_service.py
└── requirements_pip.txt
```

另外包里还会带 3 个辅助文件：

```text
部署教程.md
nginx.ioftv.conf
ioftv-python.service
```

## 一. 上传并解压

1. 在宝塔左侧打开「文件」。
2. 进入 `/www/wwwroot/`。
3. 上传压缩包并解压。
4. 解压后确认目录是 `/www/wwwroot/ioftv/`，不是多套一层目录。

## 二. 安装运行环境

服务器需要：

- `nginx`
- `nodejs`
- `pm2`
- `python3`
- `python3-venv`
- `python3-pip`
- `build-essential`

如果没装，可在 SSH 执行：

```bash
apt update
apt install -y nginx python3 python3-pip python3-venv build-essential
npm install -g pm2
```

建议 Node 用 `20` 或 `24`。

## 三. 安装 Node 依赖

前端和 IFC 已经构建好了，服务器不用重新打包，只需要装后端依赖：

```bash
cd /www/wwwroot/ioftv/server
npm install --omit=dev
```

## 四. 安装 Python 依赖

```bash
python3 -m venv /www/wwwroot/ioftv-venv
/www/wwwroot/ioftv-venv/bin/pip install --upgrade pip
/www/wwwroot/ioftv-venv/bin/pip install -r /www/wwwroot/ioftv/requirements_pip.txt
```

## 五. 启动 Node 服务

```bash
pm2 delete ioftv 2>/dev/null || true
PORT=8890 PYTHON_API_PORT=8765 pm2 start /www/wwwroot/ioftv/server/index.js --name ioftv
pm2 save
```

检查：

```bash
pm2 status
curl http://127.0.0.1:8890/health
```

## 六. 启动 Python 服务

把包里的 `ioftv-python.service` 放到：

```text
/etc/systemd/system/ioftv-python.service
```

或者直接执行：

```bash
cp /www/wwwroot/部署包里的/ioftv-python.service /etc/systemd/system/ioftv-python.service
systemctl daemon-reload
systemctl enable ioftv-python
systemctl restart ioftv-python
```

检查：

```bash
systemctl status ioftv-python --no-pager
curl http://127.0.0.1:8765/health
```

## 七. 配置宝塔站点

1. 宝塔左侧打开「网站」。
2. 新建站点，根目录填：`/www/wwwroot/ioftv`
3. 站点端口用 `8080`。
4. 打开站点「配置文件」，用包里的 `nginx.ioftv.conf` 内容覆盖。
5. 保存后重载 Nginx。

如果你是手工放配置文件，目标一般是：

```text
/www/server/panel/vhost/nginx/站点名.conf
```

## 八. 放行端口

需要同时放行：

- 云服务器安全组 `8080/tcp`
- 宝塔防火墙 `8080/tcp`

## 十. 常见问题

1. 页面能开但没数据：
   检查 `pm2 status` 和 `curl http://127.0.0.1:8890/health`
2. IFC 白屏：
   检查 `/www/wwwroot/ioftv/ifc/dist/` 是否完整上传
3. 字体报错：
   检查 `/www/wwwroot/ioftv/public/AlibabaPuHuiTi-3-45-Light/` 是否存在
4. 班组图片不显示：
   检查 `/www/wwwroot/ioftv/banzu/` 是否完整上传
5. Python 接口 502：
   检查 `systemctl status ioftv-python --no-pager`

## 十一. 后续更新

1. 只改前端：
   覆盖 `/www/wwwroot/ioftv/dist/`
2. 改 IFC 查看器：
   覆盖 `/www/wwwroot/ioftv/ifc/dist/`
3. 改 Node 后端：
   覆盖 `/www/wwwroot/ioftv/server/` 后执行 `pm2 restart ioftv`
4. 改 Python 后端：
   覆盖 `app.py` 或依赖后执行 `systemctl restart ioftv-python`
